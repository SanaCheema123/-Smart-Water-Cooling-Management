# Smart Water & Cooling Management UI v1.0

Complete responsive React/Vite dashboard styled from the supplied green smart-water reference.

Features: fixed NAVBAR/sidebar, top navbar, vertical scrolling, responsive mobile navigation, light/dark mode, live WebSocket status, sensor monitoring, analytics/WUE, demand prediction, alerts + acknowledge, recommendations, sustainability report, weather, sensor readings, REST API integration.

Backend default: http://127.0.0.1:8000
WebSocket default: ws://127.0.0.1:8000/ws/sensors

Run:
npm install
npm run dev

Then open the Vite URL (normally http://localhost:5173).
